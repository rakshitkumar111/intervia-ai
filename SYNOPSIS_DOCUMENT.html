1. Introduction & Background

In modern technological industries and global software recruitment, candidate evaluation represents an acute operational bottleneck. Conventional initial screening interviews demand extensive bandwidth from senior software architects and technical leads. This dependency results in cognitive fatigue, extended hiring turnaround cycles, and subjective assessment biases.

This project presents an Autonomous AI Virtual Humanoid Interviewer Platform. The system provides an interactive, proctored environment where an intelligent virtual persona (Dr. Sarah Mitchell) conducts synchronous spoken technical interviews. The platform incorporates low-latency WebRTC video streaming, browser-level Speech-to-Text (STT) telemetry, cognitive reasoning via Google's Gemini 3.8 Flash Large Language Model (LLM), and strict data isolation conforming to the HireVue confidentiality standard.

2. Problem Statement

Traditional technical recruitment workflows present significant structural challenges:

  • Cognitive Overhead on Engineering Staff: Senior technical personnel spend upwards of 25 hours per month conducting repetitive preliminary screening rounds, reducing active software production velocity.
  • Evaluator Inconsistency and Subjective Bias: Human interviewers apply shifting benchmarks influenced by interview fatigue, personal affinity, and varying mood baselines.
  • Scheduling Delays: Coordinating calendar availability across cross-border time zones introduces 7 to 14 days of pipeline latency per candidate.
  • Assessment Integrity and Leakage: Generic assessment platforms expose scoring rubrics directly to candidates, compromising organizational confidentiality and inviting coached exploitation.

3. Objectives of the Project

The primary engineering and architectural objectives are:

  1. Interactive Humanoid Persona: Implement a real-time conversational humanoid video avatar utilizing D-ID WebRTC DirectPlayback streaming, backed by a local realistic female avatar failover mechanism.
  2. Cognitive Question Generation: Engineer an adaptive LLM question generation engine powered by Google Gemini 3.8 Flash with session-memory to eliminate question repetition and generate dynamic follow-up questions.
  3. Speech Telemetry & Analytics: Develop an in-browser voice recognition pipeline capable of real-time transcription, speech pacing measurement (Words Per Minute), and filler vocalization (e.g., "um", "uh") tracking.
  4. 8-Dimensional Scoring Matrix: Construct an automated evaluation engine grading Technical Depth, Correctness, Relevance, Problem Solving, Communication, Depth, Practicality, and Confidence.
  5. Enterprise HireVue Protocol: Implement a confidential submission workflow where candidates receive formal tracking receipts (e.g., HV-244-8921) while internal diagnostic reports remain strictly gated for recruiters.
  6. Multi-Channel Recruiter Infrastructure: Create an automated dispatch system using real Gmail SMTP (STARTTLS 587 / SSL 465) and WhatsApp deep links, supported by one-click ReportLab executive PDF generation.

4. Methodology & System Architecture

The architecture adopts a modular micro-service pattern separating the React/TypeScript client interface from the asynchronous FastAPI backend and cloud cognitive services.

4.1 End-to-End Workflow Execution

  1. Dispatch Phase: Recruiter configures job role, seniority level, and question parameters. System creates an isolated token and transmits candidate invitations via Gmail SMTP and WhatsApp.
  2. Zero-Friction Access: Remote candidates access the session via Cloudflare HTTPS WAN tunnel without prior account registration.
  3. Interactive Interview: The virtual avatar vocalizes questions; candidate answers verbally. Client-side STT transcribes spoken words while logging verbal pacing and focus-loss incidents.
  4. Diagnostic Evaluation: Gemini 3.8 Flash assesses candidate answers against technical rubrics across 8 evaluation dimensions.
  5. Confidential Finalization: Candidate receives a formal HireVue-style receipt; scoring metrics remain inaccessible to the candidate.
  6. Executive Synthesis: Recruiter dashboard synchronizes live leaderboard standings, dispatches email completion notifications, and enables instant PDF report downloads.

7. Key Features & Novelty of the Work

  • Dual-Layer AI Resilience: Integrates a 15-second scaled cloud LLM pipeline coupled with an algorithmic Universal Fallback Engine, guaranteeing zero session crashes during API outages.
  • Strict HireVue Confidentiality Gate: Complete separation of internal evaluation data from candidate access, ensuring authentic assessment conditions and preventing coaching leaks.
  • Multi-Dimensional Scoring: Moves beyond single-percentage grading by evaluating answers across 8 independent cognitive vectors including technical depth and practical application.
  • Speech Telemetry Tele-Proctoring: Captures audio fluency, words-per-minute pacing, filler vocalization counts, and tab focus-loss incidents.
  • Autonomous Pipeline: Recruiter invite creation automatically connects to Gmail SMTP dispatch, candidate execution, and immediate PDF generation with zero manual data handling.
